Dataset Documentation

Overview

This folder contains the synthetic sales dataset used in the SQL Sales Data Analysis project.

File Included

- "sales_data.csv" — Contains 100 employee records for SQL practice and business analysis.

Dataset Columns

Column| Description
EmployeeID| Unique identifier for each employee
EmployeeName| Employee's name
Department| Department to which the employee belongs
Sales| Sales amount recorded for the employee
Target| Sales target assigned to the employee

Departments

The dataset covers five departments:

- Sales
- IT
- HR
- Finance
- Marketing

Purpose

The dataset is used to practice SQL queries, department-level analysis, employee performance evaluation, and sales target comparisons.

Data Disclaimer

This is synthetic data created for educational and portfolio purposes. It does not represent actual employees or company performance.
