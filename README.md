#SQL Sales Data Analysis

##Project Overview

This project demonstrates how SQL can be used to analyze employee sales performance, compare sales with targets, and generate insights for business reporting.

##Objectives

- Analyze sales performance across departments.
- Compare actual sales with sales targets.
- Evaluate employee-level performance.
- Practice SQL querying and data aggregation.
- Support evidence-based business reporting.

##Dataset

The project uses a synthetic sales dataset containing 100 employee records across five departments:

- Sales
- IT
- HR
- Finance
- Marketing

The dataset includes employee IDs, employee names, departments, sales, and targets. It is created for learning and portfolio demonstration purposes.

##Tools Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL
- GitHub

##SQL Skills Demonstrated

- SELECT, WHERE, and ORDER BY
- Aggregate functions such as COUNT and SUM
- GROUP BY and HAVING
- JOIN operations
- Subqueries and Common Table Expressions (CTEs)
- Window functions
- Sales target and achievement analysis

##Repository Structure

- "Dataset/" — Dataset and documentation.
- "SQL-Queries/" — SQL scripts for setup and analysis.
- "Reports/" — Business reporting and project documentation.

##How to Use

1. Download the dataset and SQL scripts.
2. Follow the database setup and CSV import instructions in the SQL documentation.
3. Run the analysis scripts in SQL Server Management Studio.
4. Review the query results to explore department and employee performance.

##Important Note

The dataset is synthetic and intended for educational and portfolio purposes. Business findings should be verified against query results before being used to support decisions.
